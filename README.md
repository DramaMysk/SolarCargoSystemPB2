#  Solar Cargo System       

## Projekta apraksts        

Solar Cargo System ir web lietotne, priekš konteineru uzskaites, pārvaldības un pievienošanas.      


---

##  Funkcionalitāte     

* Galvenā lapa ar informāciju       
* Konteineru saraksta apskate       
* Jauna konteinera pievienosana     
* Statistikas lapa (izstrādes procesā)      
* Datu ievades forma        


---


##  Konteinera pievienošana       

Var pievienot konteineru pēc sekojošās formas:      

* Konteinera ID     
* Nosaukums         
* Svars     
* Statusu       

---

## Pielietotas tehnoloģijas

* HTML — struktūra      
* CSS — dizains     
* google forms - datu ievades sistēma       
* google sheets - datu apstrādei un izvadei     
* domain name - domena pieškiršanai         
* hostings - lappas publicēšanai internetā      


---

##  Kā palaist            

   Atver index.html pārlūkprogrammā         
   Vai publicēt to hostingā ar savu domena vārdu.
